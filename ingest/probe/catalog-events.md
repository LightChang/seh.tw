# data.gov.tw catalog 全站掃描 — 文化活動資料集

基準日 2026-09-09。來源：`ingest/catalog/data-gov-datasets.csv`（53127 筆）。

## 第一層：候選清單

腳本：關鍵字比對 `資料集名稱`＋`資料集描述`，排除預算/統計/補助等行政類詞，
弱關鍵字（表演/講座/研習/工作坊/導覽）另外要求 agency 或 name 帶文化領域字樣才收，
避免把警察大學研習班、海洋委員會工作坊也掃進來。

- 掃描總筆數：53127
- 候選：**214 筆** → `ingest/catalog/event-datasets.csv`
- 欄位：dataset_id, name, agency, update_freq, formats, has_date_field, has_geo_field, download_url, license

## 第二層：優先級排序

排序準則：更新頻率 → 有無日期欄位 → 有無經緯度欄位 → 資料量 → 涵蓋範圍。

先排除已被現有 16 支 event script（及 12 支 venue/heritage/org script）覆蓋的網域，
共排除 64 筆（多數是 cloud.culture.tw／data.taipei／data.ntpc.gov.tw／
newdatacenter.taichung.gov.tw／data.cip.gov.tw／opendata.tycg.gov.tw 底下的重複子分類）。

剩餘 150 筆依準則排序後，人工複核前段結果——純關鍵字排序把「智慧財產權研討會」
「廣播電臺節目表」「步道／自行車道」「SBIR活動快訊」等因描述文字剛好含「活動資訊」
四字但實際不是文化活動的資料集也排到前面，手動剔除後選出 30 筆送第三層實測。

## 重要發現

1. **臺南文化局每月藝文活動起死回生**：`SCHEMA.md` 記載這份資料因 data.tainan.gov.tw 是
   Blazor Server + SignalR 而判定「技術限制不可用」。但 catalog 的下載網址欄位裡藏著
   另一個網域 `soa.tainan.gov.tw/Api/Service/Get/<id>`，是純 REST JSON、不需要 SignalR，
   直接打得通。這份資料 lat/lng 100% 填值、地址100%填值、內容到 2026-12，是這次掃描
   質量最好的新來源。
2. NSTM（國立科學工藝博物館，高雄）完全沒被原本 5 組 agent 摸到，一次補進 2 支活資料源
   （活動、展覽），資料很新（到 2027-03）。
3. 客委會客家文化發展中心的 `cloud.hakka.gov.tw` 開放資料平台不需要 API key
   （跟需要申請 key 的 `data.hakka.gov.tw` 是不同網站），補了六堆/苗栗兩館的活動資料。
4. 縣市層級的資料集大量「宣稱開放但實際停更」：新營演藝廳(2021)、蕭壠文化園區(2025但缺
   2026)、彰化客家活動(2025)、國資圖講座(2025)、NTL台灣學講座(2013)——都是有 API 能打
   但內容早就沒人維護，符合現有 16 支裡 taichung-culture-events 死資料的模式。
5. 宜蘭縣整個開放資料平台 `e-land.gov.tw` 對外連線逾時（非本次限流，重試2次+45秒逾時仍
   連不上），無法判斷是暫時性還是長期關站，需要日後重測。
