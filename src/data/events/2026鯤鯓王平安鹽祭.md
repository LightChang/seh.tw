description: "【鯤鯓王平安鹽祭：跨越三百年的鹽分與信仰】一場奇妙的因緣，開啟了傳承百年的盛典。回溯至 1662 年，兩段傳奇在同一塊土地上交會： 那一年，延平郡王引進了「天日曬鹽」技術，讓北門井仔腳瓦盤鹽田從此成為臺灣鹽產業的搖籃，至今屹立兩百多年，化作一座「活的建築文化資產」。 同樣在那一年，五位王爺（大千歲）駕著王船登陸鯤鯓沙汕，擇地建廟，自此守護世代萬民。這便是今日的「王爺總廟」—南鯤鯓代天府，奉祀李池吳朱范等五位王爺與萬善爺。鹽，自古象徵著避邪與祈福。當鹽產業與王爺信仰交織，便孕育出極具意義的「鯤鯓王平安鹽祭」。這場由雲管處與南鯤鯓代天府攜手打造的盛事，自 2004 年創辦以來，今年已邁入第 23 個年頭。它不僅是宗教的淬鍊，更是結合產業、文化與觀光的臺灣指標性祭典。【祭典三部曲：請鹽、祭鹽、謝鹽】這場祭典透過三個核心科儀，展現了對天地神明的敬意與生生不息的文化傳承：1. 請鹽：寶盂傳承，感念上天恩賜在祭典首日清晨，法師於井仔腳鹽田稟告眾神，感謝上天一整年的豐收與庇佑。隨後，請鹽隊伍將鹽收入寶盂，安置於鹽轎中，沿途行經興安宮、泰安宮、永隆宮，最終抵達南鯤鯓代天府，正式為祭典揭開序幕。2. 祭鹽：敕鹽祈福，匯聚神聖能量當請鹽隊伍抵達代天府後，大法師將啟動「敕鹽」科儀。從凌霄寶殿到廣場的壯觀鹽堆，法師逐一祈福淨化，賦予平凡的白鹽趨吉避凶的靈力，完成祭鹽儀式，供廣大信眾祈求平安。3. 謝鹽：返本還原，回歸天地循環祭典尾聲，最動人的篇章便是「謝鹽」。這象徵著「從何而來，便回何處」。在法師的誦經聲中，信眾親手將平安鹽撒回井仔腳鹽田，回歸大海。這場「一往一而來」的循環，不僅展現了天地生生不息的意象，更為祭典畫下了最完美的圓滿句點。三大傳統科儀請鹽科儀：11/07（六）07:00－07:20，於井仔腳鹽田迎請平安鹽。祭鹽科儀：11/07（六）09:05－11:00，進行祈願敕鹽與淨化賜福。謝鹽科儀：11/08（日）15:00－15:30，將平安鹽撒回鹽田圓滿歸真。韓國傳統祈福文化演出跨國文化盛會：特別邀請韓國傳統薩滿巫師「萬神（Mansin）」蒞臨現場，展現結合歌舞、音樂與說唱的「巫祭（Gut）」儀式，近距離體驗韓國淨化驅邪與祈求平安的傳統信仰藝術。11/07（六）：13:00－14:00、14:30－15:0011/08（日）：10:00－10:30、12:30－13:30護鹽騎士招募活動時間：11/07（六）07:00－10:55（06:30 井仔腳瓦盤鹽田集合）。騎乘路線：井仔腳瓦盤鹽田 ➔ 夕鹽段自行車道 ➔ 水晶教堂 ➔ 北門商圈 ➔ 南鯤鯓代天府（全長約 6.3 公里）。報名資訊：09/15 10:00 至 09/30 18:00 開放報名，對象為 18–70 歲具騎乘經驗者，限額 200 名（10/06 電子郵件通知錄取）。任務完賽禮：請鹽能量球、背袋、祈福旗、旅行用漱口水組及 2026 鯤鯓王平安鹽袋。報名連結：護鹽騎士線上報名套裝行程：雄獅旅遊護鹽騎士套裝行程雲嘉南祈福觀光小旅行（雄獅旅行社限定合作遊程）DAY 1 人文慢旅行：台北車站 ➔ 他里霧文化園區 ➔ 丸聚星球風味午餐 ➔ 竹崎親水公園 ➔ 番路鄉柿園導覽＆採柿體驗 ➔ 嘉義住宿。DAY 2 王爺信仰鹽鄉歲月：飯店 ➔ 南鯤鯓代天府 ➔ 「白金歲月走讀」井仔腳＆興安宮 ➔ 井仔腳風味午餐 ➔ 北門遊客中心導覽 ➔ 垂坤旗艦店採買 ➔ 返程。行程預訂：雄獅旅遊限定遊程報名"
