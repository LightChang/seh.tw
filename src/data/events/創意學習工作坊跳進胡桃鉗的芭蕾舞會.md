  # 帶著最愛的娃娃一起來場親子夢幻舞會
  
  如果有一天，最喜歡的娃娃真的動了起來，會帶著你跳進一場夢幻的芭蕾舞會嗎？
  
  今年聖誕節前，邀請孩子與家人一起走進《胡桃鉗》的世界，透過遊戲、音樂與舞蹈，認識芭蕾優雅的身體語言，與最愛的娃娃一起參加夢幻舞會、探索各國舞蹈，在歡笑與律動中感受芭蕾的魅力。
  
  不需要舞蹈基礎，只要帶著好奇心，就能自在舞動、享受親子共舞的美好時光，一起留下屬於冬日的珍貴回憶，體驗第一次跳芭蕾的樂趣。
  
   課程內容
  
  暖身派對｜一起跳進芭蕾舞會
  
  跟著音樂展開歡樂派對，透過芭蕾律動與互動遊戲舒展身體、暖開筋骨，為接下來的舞蹈體驗做好準備。
  
  遇見胡桃鉗｜喚醒魔法娃娃
  
  如果最愛的娃娃突然動了起來，會帶你展開什麼樣的冒險呢？一起認識芭蕾優雅的手姿與腳位，跟著胡桃鉗舞動，感受身體律動與舞蹈的樂趣。
  
  親子共舞｜和娃娃一起跳舞
  
  和最愛的娃娃一起共舞，透過快與慢、高與低等動作變化，激發想像力、培養身體協調，在歡笑中享受親子共舞的美好時光。

  劉淑玲
  
  11歲起進入張秀如舞蹈中心學習舞蹈，畢業於台南應用科技大學舞蹈科，擁有扎實的專業舞蹈訓練與教學經驗。
  
  曾參與高雄城市芭蕾舞團1992- 2025 年演出，累積豐富的舞台實務經驗。現任張秀如舞蹈教學系統教師，致力於芭蕾教育與舞蹈藝術推廣。
  
  熱愛芭蕾舞教學，喜歡陪伴孩子在舞蹈中快樂成長，並與學生分享芭蕾的美好與感動。期待每一位小寶貝都能在充滿愛與鼓勵的學習環境中建立自信、培養優雅氣質，也誠摯歡迎爸爸媽媽陪伴孩子一起踏上芭蕾舞的美麗旅程！
  
  許佳蓉
  
  畢業於國立臺北藝術大學舞蹈學系七年一貫制，並取得國立高雄師範大學表演藝術碩士學位。現任高雄城市芭蕾舞團舞者，曾赴美擔任南卡羅來納州哥倫比亞古典芭蕾舞團實習舞者，具備豐富的國內外表演與教學經驗。取得英國皇家舞蹈學院（RAD）Intermediate Foundation優異成績、Silver Swans銀天鵝芭蕾認證。近年持續投入舞蹈創作，於高雄城市芭蕾舞團「點子鞋」系列發表多部編創作品，並參與過高雄春天藝術節、臺灣舞蹈平台等演出與藝術教育推廣，致力於融合表演、創作與教學，探索身體與生活之間的藝術連結。
