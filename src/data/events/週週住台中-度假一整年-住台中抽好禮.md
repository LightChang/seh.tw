週週住臺中，度假一整年 抽獎活動辦法一、 活動期間與參加資格(一) 「週週住臺中，度假一整年」活動期間：自115年9月1日（星期二）00：00起至115年11月30日（星期一）23：59止。(二) 有效憑證期間：1.參與本活動之消費，應同時符合下列條件，始具參加資格： 實際住宿事實應發生於活動期間內（即實際入住日期介於活動期間內）。2.前項消費之相關發票或住宿憑證，其開立或出具日期應與前述交易時間相符，並足以證明該筆消費係發生於活動期間內。透過線上訂房平台（OTA）或旅行業者完成之訂單，除應符合前項規定外，並應以實際入住事實為準，主辦單位得向旅宿業者或相關平台進行查證。(三) 參加對象：1.限持有中華民國身分證明文件之本國國民。2.限「自然人」參加：登錄之發票或住宿憑證不得載有買受人統一編號；凡載有統一編號，或買受人為公司行號、政府機關、公營事業、公立學校、部隊或其他法人、團體者，均不具參加資格。(四) 適用旅宿業者：臺中市轄內之一般旅館、觀光旅館及民宿，且店家須參加觀光署國旅補助優惠並審核通過。適用旅宿業者名單請參考交通部觀光署「國旅補助申請系統」網站-「參與業者及優惠」。二、 登錄方式與規定(一) 參加方式：民眾於活動期間內至適用旅宿業者(詳一、活動期間與參加資格)完成住宿消費並取得合法憑證後，應完成登錄程序，始具抽獎資格。(二) 憑證類型與登錄資訊：統一發票（電子/雲端/傳統）：應填寫發票日期、發票號碼（含英文及數字）及消費金額，並上傳清晰影像。(三) 適用對象：由免用統一發票之合法登記旅宿業者提供之住宿消費，或透過線上訂房平台（OTA）或旅行業者代為訂房，且得提供可供查驗之個別訂房紀錄者。(四) 登錄內容：登錄時應填寫住宿日期、消費金額、旅宿名稱，並上傳清晰可辨識之相關憑證影像。(五) 中獎查驗規定：中獎者於領獎時，應依主辦單位通知之期限內，提供住宿憑證、免用統一發票收據、OTA平台開立之電子發票、電子收據或旅行業代收轉付收據等相關證明文件，以供查驗；未能提供、提供不全、內容不符或逾期未提出者，視為不符合中獎資格。(六) 住宿事實認定：透過線上訂房平台或旅行業者完成之訂單，應以實際入住事實為準；主辦單位得向旅宿業者進行查證。經查未實際入住者，不具抽獎資格。(七) 其他規定：本活動之相關登錄資料與憑證，主辦單位得進行查核；如有虛偽不實、偽造或變造情事，將不符合中獎資格。(八) 參加者須完成登錄事宜。(九) 登錄資料包含姓名、身份證字號、手機號碼、電子郵件（Email）、居住縣市、旅館/民宿名稱、憑證日期等，並上傳憑證照片（發票或收據）。(十) 所填資料應與領獎時之身分證明文件一致；未一致者，視為不符合中獎資格。(十一) 登錄期限：應於活動期間內完成登錄，逾期視同放棄資格。(十二) 登錄限制：每張發票或住宿憑證限登錄一次。(十三) 登錄資料責任：參加者應確保所填資料及上傳內容真實無誤，如有不實或偽造情形，主辦單位得取消資格並追究法律責任。三、抽獎辦理方式(一) 獎項內容：本活動提供之獎項包含「週週住臺中，度假一整年」1名及多項好禮，實際獎項內容、規格及數量，依主辦單位公告為準。主辦單位保留調整、變更或以等值商品替代之權利。(二) 抽獎機制：活動期間預計共3個月（115/9/1-11/30），於10、11、12月每月初辦理1場公開抽獎，並由本局政風室見證；各場次公開抽獎時間由主辦單位另行公告。(三) 每筆登錄取得之抽獎序號，若當月未中獎，得自動累積至後續月份抽獎；參加者應妥善保存原始發票、住宿憑證，及免用統一發票收據、OTA平台開立之電子發票、電子收據或旅行業代收轉付收據等相關證明文件，以利中獎時查驗；未能提供、提供不全、內容不符或逾期未提出者，視為放棄中獎資格。(四) 抽獎方式：由系統以電腦隨機方式抽出中獎序號，並留存完整紀錄。(五) 中獎限制：「週週住臺中，度假一整年」每人限中獎一次；如同一人重複中得獎項，主辦單位得取消其重複中獎資格。(六) 經查證有下列情形之一者，主辦單位得逕行取消其參加或中獎資格，並不另行補償：( 1 ) 虛偽交易或無實際住宿事實。( 2 ) 拆單、分帳或其他方式刻意增加抽獎機會。( 3 ) 使用他人名義、借名登錄或代為登錄。( 4 ) 同一消費事實重複開立憑證或重複登錄。( 5 ) 其他經主辦單位認定足以影響活動公平性之情形。(七) 如有利用他人名義或其他規避本條規定之情形，經查證屬實者，主辦單位得取消其參加或中獎資格。(八) 前述有關不當參與之認定，主辦單位保有最終審認權。四、 中獎公告與領獎(一) 公告方式：中獎名單將公告於活動官方網站，並透過以Email寄發中獎通知書及電話聯繫通知中獎者中獎資訊。(二) 兌獎期限：中獎者應於接獲通知後7日內辦理兌獎事宜，逾期未回覆者，主辦機關得取消中獎資格；如中獎人提供資料缺漏或錯誤需補件，應於主辦機關通知補件次日起5日內辦理補件事宜，逾期未辦理者，主辦機關得取消中獎資格。(三) 查驗機制：中獎者於領獎時，應依主辦單位通知提供原始發票、住宿憑證，及免用統一發票收據、OTA平台開立之電子發票、電子收據或旅行業代收轉付收據等相關證明文件，以供查驗；未能提供、提供不全、內容不符或逾期未提出者，視為不符合中獎資格。（收據無蓋章證明，視為無效）(四) 聯繫失效：因中獎者填寫之資料錯誤或不完整，致無法聯繫者；又或因中獎者未查看或設定關閉接收相關中獎通知，以致未知悉自身中獎，皆視為放棄中獎資格。(五) 領獎身分：獎項應由中獎者本人領取；如需委託他人代領，應依主辦單位規定填具委託代理人申請書，並檢附相關證明文件辦理。(六) 逾期未領取之處理：中獎者未於指定領獎期限內完成領獎程序者，視為自動放棄中獎資格；其未領取之獎項，將於本活動最終一次抽獎時統一辦理重新抽出。五、 獎項交付與稅務(一) 交付方式：1.本活動小額獎項寄送地區僅限台灣本島，中獎者實際居住地點非在中華民國境內，中獎品項之運送費用及衍伸費用須由中獎人負擔。機車獎項需至主辦單位指定門市或地點領取。2.主辦單位僅提供基本運送；如涉及偏遠地區運送、無電梯樓層搬運或額外施工需求等，相關費用由中獎人自行負擔。(二) 獎項限制：不得要求更換顏色、規格、轉讓或折換成現金。中獎獎項日後之使用保固與維修，主辦機關及執行單位概不負責，獎項經兌換、簽收受領後，如有遺失、盜領、自行拋棄、毀損，恕不補發。(三) 主辦機關與執行單位保留審核、決定及變更獎項內容之權利，如因不可抗拒之因素，主辦機關與執行單位有權更換獎項為等值商品。(四) 稅務規定：中獎人應依中華民國稅法相關規定辦理稅務申報及繳納事宜；中獎獎項價值超過新臺幣1,000元者，依法列入個人年度綜合所得；超過新臺幣20,000元者（含20,000元），應依規定扣繳10%稅額。中獎者如為未滿18歲之未成年人，應檢附法定代理人同意書及身分證明文件(如：戶籍謄本)，辦理領獎中獎人如未依規定繳納稅額或提供相關文件，視同放棄中獎資格。相關稅務規定如有修正，依最新法令辦理。主辦單位依法代收中獎稅金，若中獎者不願意提供資料，或未能先行依法繳納稅額，即視為放棄中獎資格。六、 個人資料保護參加者同意主辦單位蒐集、處理及利用個人資料作為活動用途，並得提供予執行單位使用，相關作業依個資法辦理。七、 系統與技術風險因網路傳輸、設備異常或其他不可歸責於主辦單位之事由，致參加者資料登錄失敗、延遲或錯誤者，主辦單位不負相關賠償責任；參加者不得因此提出異議或請求補償。八、 防弊與查核機制(一) 查核權限：主辦單位得依活動需求進行查核、抽查及風險控管，包含但不限於憑證真實性、住宿事實及交易合理性。(二) 查核配合義務：主辦單位得要求參加者提供相關佐證文件（如住宿證明、付款紀錄等），參加者應予配合，不得拒絕；未能配合查核、提供不全或內容不符者，視為不符合參加或中獎資格。(三) 違規處理：經查證為不合理交易行為，主辦單位得逕行取消資格，並追回已領取之獎項。(四) 風控機制：本活動導入風控及異常偵測機制（包含重複登錄、異常消費型態等），以確保活動之公平性及正當性。九、 法律風險與權利保留條款：(一) 最終解釋權：主辦單位保有活動最終解釋權。(二) 動調整權：主辦單位得視情況調整或終止活動。(三) 不可抗力：因天災、疫情或其他不可抗力事由，致本活動無法如期舉行、延遲或變更內容者，主辦單位不負相關賠償責任，參加者不得提出異議或請求補償。(四) 法律責任：如有不當行為，將依法追究相關責任。(五)管轄法院及調解：因本活動所生之爭議雙方同意先在臺灣臺中地方法院調解，若調解不成立而有爭訟之必要，雙方合意以臺灣臺中地方法院為第一審管轄法院。(六) 參與與同意：參加者參與本活動即視為已閱讀並同意遵守本活動辦法及相關規定，如有違反，主辦單位得取消其參加或中獎資格，並依法追究相關責任。(七) 稅務補充：中獎人應依中華民國稅法相關規定辦理稅務申報及繳納事宜；如依法需扣繳稅額者，應先行繳納始得領獎，未依規定辦理者，視同放棄中獎資格。
