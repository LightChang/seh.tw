description: |-
  onedotzero於1996年集結了一群全新概念的影像藝術家，以非傳統的影像藝術創作，在倫敦展開第一次數位影像創作展，六年來已成為影像藝術愛好者們引領企盼的年度盛會，堪稱全球最知名、最具影響力的數位影展。支持各種創新突破的影像藝術、打破傳統的製作方式，鼓勵新一代的影像工作者發揮其創作潛能。結集的作品內容含括了實驗短片、廣告片、商業設計、音樂錄影帶、數位劇情長片、電玩遊戲動畫以及互動式媒體藝術等。此次onedotzero taipei 1.0動態影像藝術展透過台北市立美術館、國巨基金會的贊助與主辦；英國文化協會、貿易商務部的協辦，以及聯合報系、東風電視台、xfuns與idn等媒體的協辦下，我們將聽到，在瞬息萬變的數位時代中，藝術與科技間的對話，並進一步體會未來影像創作的無限可能。藉由藝術家的創意與想像力，加上新時代的新科技及多元化的媒材所延伸出來的領域，讓冰冷的科技開始有了人文的溫度，科技也讓更多的夢想得以實現。
  
  此次展覽活動內容可分為三大子題:數位影片的放映、研討會及座談會、及現場數位影像表演。影片放映的部份可分為數位短片、數位劇情長片、及工作室訪談紀錄三部份。研討會及座談會則邀請了國際間頂尖的傑出藝術家出席，藉由作品的發表與創作理念的分享，與台灣影像工作者進行現場交流。現場數位影像表演將呈現螢幕外的現場演出，結合Club Culture產生高度互動的數位影像表演。
